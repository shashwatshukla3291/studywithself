# Study Sprint

A four-step study planner that helps turn one overwhelming task into a focused work session, then keeps a record of completed sprints.

## Live site

Add your GitHub Pages link here after publishing. If your GitHub username is `shashwatshukla3291` and the repository is named `study-sprint`, the URL will be:

https://shashwatshukla3291.github.io/studywithself/

## What it does

- Guides you through four screens: choose a task, pick a sprint length, focus, and review completed sessions
- Offers 5, 15, 25, and 40 minute focus sessions
- Includes a working pause, resume, and reset timer
- Plays a short alarm tone when a sprint completes
- Saves completed session names, dates, and durations in a history table using this browser's local storage
- Runs without an account or backend

## Built with

HTML, CSS, and JavaScript.

## Note

The session history stays in the browser where it was created. It does not sync between devices. The timer is a focus aid; keep the page open while a sprint is running. Your browser may require sound to be enabled for the completion tone.
